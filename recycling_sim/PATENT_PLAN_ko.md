# 특허 출원 계획 — 각도 선택 다중통과 재순환 TEOLED의 정면 효율 향상 구조

> 이 문서는 출원 전략과 명세서 초안 설계용입니다. 법률 의견이 아닙니다.
> - 선행기술은 웹 검색 스니펫으로 확인한 것이라, 각 특허의 청구항 원문·우선일·권리상태는 확인하지 않았습니다.

## 0. 가장 먼저: 자기 공개(본인 논문)와 출원 시점

- **Nature 투고 원고(η_sta = p/(p+(1−p)A′))가 공개되면 그 자체가 선행기술이 됩니다.**
  - 아직 공개 전이면, 공개 전에 국내 출원(최소 임시명세서)을 먼저 하세요. 프리프린트, 학회 발표, 포스터도 공개에 해당합니다.
- **공지예외(grace period)는 나라마다 다릅니다.**

  | 나라 | 공지예외 |
  |---|---|
  | 한국 | 12개월(주장 필요) |
  | 미국 | 12개월 |
  | 일본 | 12개월 |
  | 중국 | 사실상 없음(학술 공개는 극히 제한적) |
  | 유럽(EPO) | 사실상 없음 |

  유럽과 중국까지 권리를 원하면 **공개 전 출원이 유일한 방법**입니다.
- **권장 흐름**
  1. 한국 임시명세서 출원(논문 원고 + 이 계획의 실시예로 빠르게 우선일 확보)
  2. 12개월 안에 보정한 정규 명세서와 PCT 출원
  3. 30/31개월에 미국, 유럽, 중국, 일본 진입
- **원고와 이번 후속 결과(11절)를 구분하세요.**
  - 원고에 이미 들어간 내용: 기본 개념, 식, 기본 구조 → 공개되면 신규성이 사라집니다.
  - 후속 결과: 금속 없는 광경로, 산화물 DBR, 개선 거울, 공정 호환 산란층, 상부 스페이서, BE 저굴절 조건 → 개량 발명으로 따로 출원할 수 있습니다.

- **(a) TEOLED 내부에 일체화한 특정 배치**
  - 산란층이 하부 투명전극 바로 아래에 있고 유기층과 굴절률이 정합되어, 도파 모드까지 전부 재순환에 참여합니다.

  - 정지대 적색 detuning
  - 저굴절막 n ≤ 1.1 조건

## 3. 청구항 초안 (A, 장치)

**독립항 1 (구조 + 기능 한정, 상위)**
> 기판; 상기 기판 상의 반사층; 상기 반사층 상에 배치되고 굴절률 n_s가 1.5 이하인 평탄한 저굴절 스페이서층; 상기 스페이서층 상에 배치되며, 굴절률 1.7–2.0의 매트릭스와 그 안에 분산된 산란체를 포함하고 상면이 평탄화된 광 무작위화층; 상기 광 무작위화층 상에 직접 접하는 투명 제1전극; 상기 제1전극 상의 유기발광층; 상기 유기발광층 상의, 금속 박막을 포함하지 않는 투명 제2전극; 및 상기 제2전극 상에 배치되어 상기 유기발광층의 발광 피크 파장에서 법선 방향 광은 투과시키고 사선 방향 광은 반사하도록 고굴절층과 저굴절층이 교대로 적층된 각도 선택 필터;를 포함하고,
> 상기 각도 선택 필터에서 반사된 광은 상기 광 무작위화층에서 진행 방향이 변경된 뒤 상기 반사층에서 반사되어 상기 각도 선택 필터에 다시 입사하는, 유기발광소자.

**독립항 3 (표시장치)**: 위 소자를 화소로 포함하고, 봉지가 기체 갭인 표시장치.

**독립항 4 (제조방법, B 출원의 핵심)**
> 반사층 형성 → 스페이서 증착 → 산란체 분산 고굴절 잉크 코팅·경화 → 동일 계열 잉크로 평탄화 → 상온 스퍼터 투명전극 → 유기층 → 금속 없는 상부전극 → 상온 또는 저손상 스퍼터 유전체 필터. 전 공정의 최고 온도는 250 °C 이하.

**청구항 작성 주의점**
- **파라미터 청구(A′ 수치 등)만으로 독립항을 세우지 마세요.**

  - 넣으려면 명세서에 A′ 측정법(적분구 반사·투과 측정 + 모델)을 정의해야 합니다.
- **독립항에 숫자 범위를 너무 많이 넣지 마세요.** 회피가 쉬워집니다. 숫자는 종속항으로 내립니다.

## 4. 명세서 구성 (한국 특허 양식)

1. **기술분야**: 유기발광소자, 정면 휘도·전류효율 향상.
2. **배경기술**
   - 강공진 TEOLED의 한계: 스펙트럼 협소화, 각도 색변화, 금속 흡수.
   - 외부 광추출 필름의 한계.
   - 위 선행 특허 인용(공정하게 기재).
3. **해결하려는 과제**: 스펙트럼을 깎지 않고 정면 cd/A를 높이고, 왕복 손실을 낮춘 내부 일체형 구조.
4. **과제의 해결 수단**: 청구항 대응 문장.
5. **발명의 효과**: 강공진 대비 ×2–4(모델), EQE 동시 증가, 색좌표 유지.
6. **도면** (기존 그림 재활용)

   | 도 | 내용 | 기존 자료 |
   |---|---|---|
   | 1 | 단면 구조(TE 기본형) | 새로 그림 |
   | 2 | 동작 원리(필터 반사 → 무작위화 → 재입사) | 새로 그림 |
   | 3 | 필터의 각도·파장 투과 지도 | 기존 그림 |
   | 4 | A′ × FWHM 승패 지도 | `amap_phase` |
   | 5 | 구조별 정면 cd/A 비교 | `arch_ranking` |
   | 6 | 왕복 손실 예산 | `arch_budget` |
