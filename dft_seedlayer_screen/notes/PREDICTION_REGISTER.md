## 지표

- 정의: D = (결합 자리 수 × P_trap(E_b)) / SASA. 단위는 1000 Å²당 개수다.
- P_trap = 1 − Φ((E* − E_b)/0.10)이다.
- E* = 0.30 eV(스크리닝 수준). 실험 데이터가 아니라 Konica 특허 데이터로 정했다. 범위는 0.25–0.35 eV다.
- 결합 자리: 고립전자쌍이 있는 N(2배위 고리 N, 니트릴 N)과 P=O의 O다. 금속에 배위된 N과 π 자리는 제외한다.
- 근거: Konica US 9,923,166의 10종에서 ρ(D) = 0.891, ρ(E_b) = -0.455, ρ(특허 ΔEef) = 0.818.
- 스크립트: `scripts/174_two_tier_descriptor.py`. 결과: `runs/two_tier.json`.

## 예측 (Ag 연속화 두께가 얇은 순)

1. **HATCN**이 가장 얇다. D가 다른 물질의 2.7배 이상이다.
2. **B3PyMPM < TPBi.** E_b는 같은 등급이고(0.42 대 0.46 eV) D는 2.1배 차이 난다(7.9 대 3.7).
   - 자리 밀도 축을 시험한다.
   - E_b 단독 지표는 반대(TPBi ≤ B3PyMPM)로 예측한다.
3. **Bphen < BCP.** D는 비슷하다(4.9 대 4.1). E_b는 킬레이트 유무로 0.62 대 0.47이다.
   - 두 물질 모두 E* 위라서 지표 D는 거의 같은 두께를 예측한다.
   - 차이가 크게 나면 E* 위에서도 결합 세기가 중요하다는 뜻이다. 지표에 결합 세기 항을 더해야 한다.
4. **B3PyMPM ≤ Bphen.** D는 7.9 대 4.9로 B3PyMPM이 크다. E_b는 Bphen이 크다.
   - 열린 질문이다. 결과로 어느 축이 우세한지 판정한다.
5. **아민 HTL(NPB, TAPC)은 seed 효과가 없다.** D = 0이다. 맨 유리 위와 같은 두께로 예측한다.
6. Bphen:Cs₂CO₃ 위는 neat Bphen보다 얇고, HATCN보다 두껍다. Cs 자리가 0.89 eV다.

## 판정 기준

- 측정량: 같은 증착 속도(≥ 1 Å/s)에서 Ag 두께 단계별 면저항. Rs가 처음 측정되는 두께와 Rs(8 nm)를 본다.
- 예측 2, 5가 맞고 3에서 차이가 작으면, 두 단계 지표를 채택한다.
- 예측 2가 틀리면(TPBi ≤ B3PyMPM), 등급이 섞인 3등급에서는 자리 밀도가 통하지 않는다는 뜻이다. Konica 결과는 피리딘 계열에만 한정한다.

## 지표가 다루지 않는 것

- 막 형태다. 결정화, Tg, 배향이 해당한다. Konica No04 대 No05는 이성질체인데 면저항이 23배 다르다.
- 클러스터 이동과 합체(coalescence)다.
- PO-T2T는 가려진 triazine N 3개도 결합 자리로 셌다. 자리별 E_b를 쓰면 D가 줄어든다.
- Alq3은 퀴놀리놀레이트 O가 Al에 결합해 있어서 결합 자리 0으로 셌다.

## HAT 유도체 설계에 주는 영향

- 하드 조건을 통과한 17종을 D로 다시 정렬했다. HATCN 이상인 후보는 0종이다.
  - HATCN의 D는 38.113이고, 후보 최대는 32.362다.
- 축합 고리나 아릴을 붙이면 SASA가 늘어 면밀도가 줄어든다.
- "HATCN을 이기는 후보가 없다"는 결론은 D 기준에서 더 강해진다.
