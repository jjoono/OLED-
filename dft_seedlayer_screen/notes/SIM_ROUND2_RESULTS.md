## 2. Ag_n (n = 1–4): HATCN 대 MoOx (Mo₃O₉), PBE0-D3

Ag 원자당 Mulliken 전하(평면형과 입체형의 범위):

| n | HATCN | MoOx |
|---|---|---|
| 1 | +0.58 | +0.72 |
| 2 | +0.08 ~ +0.12 | +0.27 ~ +0.38 |
| 3 | +0.15 | +0.28 |
| 4 | +0.08 ~ +0.09 | +0.24 ~ +0.27 |

평면형과 입체형의 에너지 차이. E(평면) − E(입체)이고 D3를 포함한다. 단위는 eV. "기판 몫"은 자유 Ag_n의 차이를 뺀 값이다.

| n | HATCN 전체 | HATCN 기판 몫 | MoOx 전체 | MoOx 기판 몫 |
|---|---|---|---|---|
| 2 | +0.28 | +0.28 | −0.31 | −0.31 |
| 3 | −0.24 | −0.30 | +0.22 | +0.26 |
| 4 | −0.08 | +0.09 | **+1.35** | **+0.97** |

해석
- **전하 결과는 확실하다.** HATCN 위 Ag 클러스터는 n ≥ 2에서 원자당 +0.15 이하로, 거의 중성 금속처럼 자란다. MoOx 위 Ag는 n = 4까지 원자당 +0.24 이상의 양이온으로 남는다.
- 이 결과는 문헌 조사에서 반박된 "Ag의 전하 부호 = 판별 기준"과 다르다. 판별 기준은 **클러스터가 커질 때 전하가 돌아오느냐**다.
- **형태 결과는 확신도가 중간이다.** n ≥ 3에서 MoOx는 입체(3D) 클러스터를 강하게 선호하고(n = 4에서 기판 몫 +0.97 eV), HATCN은 평면이거나 중립이다. 그러나 다음 한계가 있다.
  - n = 2에서는 방향이 반대다.
  - 클러스터 구조는 GFN2로 짧게만 최적화했다.
  - MoOx는 표면이 아니라 클러스터로 모델링했다.
- 기존 cluster_growth(133)의 전하 경향과 일치한다.

## 3. CCSD(T) 벤치마크: Ag 원자–배위자 결합 (CP 보정)

| 사이트 유형 | 대표 분자 | 스크리닝 수준 (PBE0-D3/SVP, CP 없음) | PBE0-D3/TZVP CP | CCSD(T)/TZVP | 스크리닝 − 기준 |
|---|---|---|---|---|---|
| 고리 N (ETL·phen) | 피리딘 | 0.373 | 0.270 | **0.177** | +0.20 |
| 다이아진 N (HAT 코어) | 피라진 | 0.306 | 0.212 | **0.120** | +0.19 |
| π hollow (호스트·HTL) | 벤젠 | 0.205 | 0.168 (문헌 D3 0.17) | **≥0.084** (문헌 0.10) | ≤ +0.12 |
| 니트릴 N | MeCN | 0.186 | 0.099 | **≥0.031** | ≤ +0.15 |

계산 방법
- CCSD(T)/TZVP는 다음 focal-point 값이다: FNO-UCCSD(T)/SVP + [MP2/TZVP − MP2/SVP].
- MeCN에서는 FNO-UCCSD(T)/TZVP를 직접 계산했다(0.031 eV). focal-point 추정값(0.033 eV)과 0.002 eV 차이다.
- 일반 UCCSD(T)는 15 GB 메모리 안에서 OOM이 났다(14 GB). 그래서 FNO를 썼다.
- 거리는 PBE0 최적값을 썼다.
  - 피리딘·피라진(고리 N): CCSD(T) 최적 거리가 0.1 Å 더 멀고, 값 차이는 0.005 eV 이하다.
  - 벤젠과 MeCN(약결합): CCSD(T) 곡선이 PBE0 거리 +0.15 Å에서도 계속 올라간다. 벤젠은 3.29 Å에서 0.050 대 0.036, MeCN은 2.77 Å에서 0.046 대 0.022(SVP). 그래서 이 둘의 기준값은 하한이다.
  - 실제 과대평가 폭은 이 둘에서 표보다 작을 수 있다(0.02–0.03 eV 정도).

결론
- **순위는 유지된다.** 고리 N > 다이아진 N > π > 니트릴.
- **절대값은 0.12–0.20 eV 과대평가된다.** 원인은 BSSE 0.04–0.10 eV(N 사이트에서 크다)와 PBE0 자체 0.08–0.11 eV다.
- 약결합 물질(ETL·HTL, 스크리닝 0.3–0.5 eV)의 실제 결합은 0.1–0.3 eV일 가능성이 크다. 따라서 "0.5 eV 문턱"은 같은 계산 수준 안의 상대 순위로만 쓴다.
- HATCN(1.63 eV)과 Bphen:Cs(0.90 eV)는 전하 이동 결합이라 이 보정을 그대로 적용하지 않는다. 피라진 N 하나는 CCSD(T)에서 0.12 eV에 그친다. 즉 HATCN의 결합은 N 한 개가 주는 공여 결합이 아니라 LUMO로 전하가 넘어가는 결합이다.
- Ag(0)–N-헤테로고리/니트릴 CCSD(T) 기준값은 문헌에 없다(조사 공백 9번).

## 4. N 1s ΔSCF (PBE0, 표적 N에 cc-pCVTZ): XPS 판정 기준

중성 HATCN의 같은 종류 N 대비 이동:

| N | 이동 (eV) | 수렴 | 실험과 비교 가능 |
|---|---|---|---|
| Ag와 결합한 aza N | **−0.89** | 수렴 | 가능 |
| Ag 쪽 니트릴 N | +0.05 | 수렴 | 가능 |
| Ag에서 먼 aza N | 미정 | 두 번 모두 미수렴 (405.51, 400.78 eV) | 사용하지 않음 |
| 고립 음이온 aza / 니트릴 | −5.19 / −2.68 | 수렴 / 미수렴 | 불가 (진공에서 −1 전하) |
| HATCN⁻Cs⁺ 이온쌍 aza / 니트릴 | 계산 중 | | |

중성 HATCN의 aza와 니트릴 N은 0.56 eV 떨어져 있다.

**판정 기준**
- Ag를 얇게 올린 HATCN에서 니트릴 피크 아래쪽으로 약 0.9 eV 낮은 새 성분이 나타나면, aza 포켓에 Ag가 결합했다는 증거다.
- 피크 전체가 함께 이동하면 계면 준위 정렬(밴드 휨) 같은 다른 효과다.
