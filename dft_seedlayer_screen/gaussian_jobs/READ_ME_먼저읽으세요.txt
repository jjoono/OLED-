 Ag 확산장벽 계산 - 워크스테이션 실행 안내
================================================================

준비물: Gaussian 16 (G16W) 하나. 그 외에는 아무것도 설치하지 않습니다.
        파이썬도, conda도 필요 없습니다.

----------------------------------------------------------------
[1단계] 압축을 풉니다
----------------------------------------------------------------
gaussian_jobs 폴더를 통째로 풀어 놓습니다.
경로에 한글이나 띄어쓰기가 없는 곳이 안전합니다.

  좋은 예:  E:\JHKim\gaussian_jobs
  피할 곳:  C:\Users\홍길동\내 문서\...

----------------------------------------------------------------
[2단계] Gaussian 설치 위치를 확인합니다
----------------------------------------------------------------
g16.exe 가 C:\G16W\g16.exe 에 있으면 아무것도 고치지 않습니다.

다른 곳에 있으면 RUN_ALL.bat 을 오른쪽 클릭 - 편집 으로 열어
위에서 12번째 줄

  set "G16DIR=C:\G16W"

여기 경로만 실제 폴더로 고칩니다. g16.exe 는 빼고 폴더까지만 씁니다.

----------------------------------------------------------------
[3단계] 실행합니다
----------------------------------------------------------------
RUN_ALL.bat 를 더블클릭합니다. 검은 창에 한 줄씩 지나갑니다.

  [17:40:35.21] Al4O6_t0_z0
  [17:41:20.66] Al4O6_t0_z1
  ...

전체 174개, 32코어 기준 3~8시간쯤 걸립니다.

* 중간에 창을 닫아도, 재부팅해도 괜찮습니다.
  다시 더블클릭하면 끝난 것은 건너뛰고 이어서 합니다.
* 실패한 계산은 건너뛰지 않고 다시 시도합니다.

----------------------------------------------------------------
[4단계] 잘 돌고 있는지 확인하는 법
----------------------------------------------------------------
계산 중인 폴더(예: gaussian_jobs\Al4O6)를 탐색기로 열어 둡니다.

  * .out 파일이 생기고 크기가 커지고 있으면  -> 정상
  * .out 크기가 몇 분째 그대로면              -> 끝났거나 멈춤
  * Gau-xxxx.rwf 같은 임시파일이 있으면       -> 계산 중

.out 파일을 메모장으로 열어 맨 아래를 봅니다.

  "Normal termination of Gaussian 16"  -> 성공
  "Error termination"                  -> 실패 (그 줄 위쪽에 이유가 있음)

작업 관리자로 볼 때는 "세부 정보" 탭을 보세요.
찾을 이름은 g16.exe 가 아니라 l502.exe, l914.exe 처럼
l 로 시작하는 파일들입니다. Gaussian 은 이것들을 차례로 부릅니다.

----------------------------------------------------------------
[5단계] 끝나면
----------------------------------------------------------------
마지막에 이런 줄이 나옵니다.

  ran 174 successfully, 0 already done, 0 failed

gaussian_jobs 폴더 전체를 압축해서 보내주세요.
용량이 크면 .out 파일만 모아 보내셔도 됩니다.

----------------------------------------------------------------
문제가 생기면
----------------------------------------------------------------
* "Gaussian not found" 후 멈춤
    -> 2단계의 G16DIR 경로가 틀렸습니다.

* 창이 순식간에 닫힘
    -> 시작 - cmd 실행 후 아래를 붙여넣으세요. 오류가 화면에 남습니다.
       cd /d E:\JHKim\gaussian_jobs
       RUN_ALL.bat

* galloc: could not allocate memory
    -> 이 PC 램이 24 GB 미만입니다. 아래 [메모리 줄이기] 참고.

* 계속 "did NOT finish normally"
    -> 그 폴더의 .out 파일 하나만 보내주시면 원인을 봐 드립니다.

----------------------------------------------------------------
[메모리 / 코어 수 바꾸기]
----------------------------------------------------------------
.gjf 파일들의 첫 두 줄이 이렇게 되어 있습니다.

  %NProcShared=32
  %Mem=24GB

이 PC 사양과 안 맞으면 바꿔야 합니다. 메모장으로 하나씩 고치지 말고
아래를 메모장에 붙여넣어 fix.bat 으로 저장한 뒤 더블클릭하세요.
(gaussian_jobs 폴더 안에 저장)

  @echo off
  set NEWPROC=16
  set NEWMEM=8
  for /r %%F in (*.gjf) do (
    powershell -NoProfile -Command ^
      "(Get-Content '%%F') -replace '^%%NProcShared=.*','%%NProcShared=%NEWPROC%' -replace '^%%Mem=.*','%%Mem=%NEWMEM%GB' | Set-Content '%%F'"
  )
  echo done
  pause

NEWPROC 와 NEWMEM 숫자만 이 PC에 맞게 고쳐서 쓰시면 됩니다.
