================================================================
 Ag 확산장벽 계산 - 워크스테이션 실행 안내
================================================================

준비물: Gaussian 16 (G16W) 하나. 그 외에는 아무것도 설치하지 않습니다.
        파이썬도, conda도 필요 없습니다.

----------------------------------------------------------------
[1단계] 압축을 풉니다
----------------------------------------------------------------
이 폴더(gaussian_jobs)를 통째로 바탕화면 같은 곳에 풀어 놓습니다.
경로에 한글이나 띄어쓰기가 없는 곳이 안전합니다.

  좋은 예:  C:\Ed\gaussian_jobs
  피할 곳:  C:\Users\홍길동\내 문서\...

----------------------------------------------------------------
[2단계] Gaussian 설치 위치를 확인합니다
----------------------------------------------------------------
탐색기에서 g16.exe 파일이 어디 있는지 찾습니다.
보통 아래 둘 중 하나입니다.

  C:\G16W\g16.exe
  C:\Program Files\G16W\g16.exe

만약 C:\G16W\g16.exe 가 아니라면, RUN_ALL.bat 파일을
마우스 오른쪽 클릭 - 편집 으로 열어서 위에서 6번째 줄

  set "G16DIR=C:\G16W"

여기의 경로를 실제 위치로 고칩니다. g16.exe 는 빼고 폴더까지만 씁니다.
C:\G16W\g16.exe 가 맞다면 아무것도 고치지 않습니다.

----------------------------------------------------------------
[3단계] 실행합니다
----------------------------------------------------------------
RUN_ALL.bat 를 더블클릭합니다.

검은 창이 뜨고 아래처럼 한 줄씩 지나갑니다.

  [14:23:01] HATCN_t0_z0
  [14:23:44] HATCN_t0_z1
  ...

이게 정상입니다. 그대로 두시면 됩니다.
전체 174개이고, 32코어 기준으로 3~8시간쯤 걸립니다.

* 중간에 창을 닫아도 괜찮습니다.
  다시 더블클릭하면 이미 끝난 것은 건너뛰고 이어서 합니다.
* 컴퓨터를 재부팅해도 마찬가지입니다.
* 밤새 돌리셔도 됩니다.

----------------------------------------------------------------
[4단계] 끝나면
----------------------------------------------------------------
마지막에 이런 줄이 나옵니다.

  finished: 174 run, 0 already had logs

그러면 gaussian_jobs 폴더 전체를 다시 압축해서 보내주세요.
용량이 크면 .log 파일만 모아 보내셔도 됩니다.

----------------------------------------------------------------
문제가 생기면
----------------------------------------------------------------
* "Gaussian not found" 라고 나오고 멈춤
    -> 2단계의 G16DIR 경로가 틀렸습니다.

* 창이 순식간에 닫힘
    -> 시작 - cmd 를 실행하고, 검은 창에 아래를 붙여넣으세요.
       cd /d C:\Ed\gaussian_jobs
       RUN_ALL.bat
       이러면 오류 메시지가 화면에 남습니다.

* 한 폴더에서만 계속 실패
    -> 그 폴더의 .log 파일 하나만 보내주시면 원인을 봐 드립니다.
       나머지는 계속 진행됩니다.

----------------------------------------------------------------
참고: 무엇을 계산하나
----------------------------------------------------------------
후보 물질 23종 위에서, 은(Ag) 원자 하나가 결합한 자리에서
옆자리로 옮겨가는 데 필요한 에너지 장벽(E_d)을 구합니다.

폴더 하나가 물질 하나이고, 그 안의 파일들은 은 원자를 조금씩
옮긴 상태들입니다. 계산 방법은 PBEPBE/Def2SVP 입니다.

INDEX.csv 에 물질별 원자 수와 계산 개수가 정리되어 있습니다.
